### Source register operational details

Model binary hashes, precise bytes and fetch timestamps only become available after the models genuinely download. Similarly, no LFW image hash, person sample count or LFW train/test result is represented as an actual outcome until local execution. All such manifests are written automatically by the Python scripts and ignored from GitHub.

The original Learning Log's example results were **not** recreated, claimed, or imported as outputs. Actual software versions, source files and predictions are generated by the executing local environment. For peer feedback, save genuine permission-cleared records separately if collected later.
